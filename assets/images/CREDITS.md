# Photo credits

Every photo bundled with AgroZen comes from Wikimedia Commons. The paths and
credits live in `lib/presentation/ui/broiler_photos.dart`, and Settings →
About → Photo credits shows them in the app. A test fails if a `.jpg` in this
folder has no credit. Each file was resized to 1200 px on the long side and
re-saved as JPEG. The finisher photo was also cropped slightly on the left.
