# Default Prompt Enhancer Rule (`enhance-prompt`)

Always apply the `enhance-prompt` skill (`.agents/skills/enhance-prompt/SKILL.md`) and `DESIGN.md` as the default pre-processing step for every user request in AgroZen.
- Transform rough or voice-transcribed requests into structured specifications (Purpose & Vibe, `DESIGN SYSTEM (REQUIRED)`, Numbered Page/Feature Structure, and Ross-308 Broiler Domain Acceptance Criteria).
- Present the enhanced prompt specification clearly in your response and execute it to completion.
